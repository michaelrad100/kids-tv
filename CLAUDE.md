# Kids TV (Mala TV and Maya TV)

A kids' video player built on Time Train's player (`~/Documents/claude/code/time-train`): it opens straight to the next video, shields taps from wandering off to YouTube, keeps sound off during ads, gives a star per finished video, and keeps grown-up settings behind a press-and-hold lock. Mala is 8; Maya's age isn't known yet, so ask before picking videos for her.

- **Every app change reaches both channels.** Mike asked for this explicitly. `mala/` (Mala TV) and `maya/` (Maya TV) each hold only their own list (`videos.js`), icons and manifest; their `index.html` sets `window.KID` and loads the shared `tv.js` and `tv.css`. Player and app changes go in those shared files (or the shared server), never in one channel's folder. Bump `tv.js?v=` / `tv.css?v=` in every channel's `index.html` when they change, so iPads load the new copy. The root `index.html` is the "Who's watching?" page.
- **Topics:** `videos.js` is `window.VIDEOS = { "Topic": [[id, title, channel, length], ...] }`. Topics show as shelf sections in that order, and playback runs through one topic before the next. Panel adds carry a topic too and join that section.
- **Mike sends links in chat** → `node scripts/add-video.mjs <mala|maya|both> "<topic>" <link> [<link> ...]`, then shorten the YouTube titles in `videos.js` to something an 8-year-old can read on the board, then commit and push to `main`. It bumps that channel's `videos.js?v=`. Ask which kid if he doesn't say. Mention any it flags as not family-safe or skips.
- **Picking videos:** age-appropriate for the kid, from kid-focused or well-known channels, embeddable, and marked family-safe. Read transcripts when possible (Supadata key at `~/.config/supadata/api-key`; YouTube blocks direct transcript fetching from this machine), and say so when a pick couldn't be transcript-checked.
- **Mike adds from the app** → a channel's grown-ups panel posts to the list server, [kids-tv-list](https://github.com/michaelrad100/kids-tv-list) (private), running on Railway in the michaelrad-me project at kids-tv-list-production.up.railway.app (deploy with `railway up --service kids-tv-list`). It keeps, per kid, added and taken-off videos on top of that channel's `videos.js`. Adding or removing needs the grown-up code (`GROWNUP_CODE` on the server; `1234` locally), which is the same for every channel. A new kid needs a folder here and a name in the server's `KIDS`.
- If the list server can't be reached, panel adds are saved on that device only, and the panel says so.
- Served at michaelrad.me/tv (so michaelrad.me/tv/mala and /tv/maya): the michaelrad.me site copies this repo's `main` in when it rebuilds on Railway, which `.github/workflows/rebuild-michaelrad-me.yml` triggers on every push to `main` (RAILWAY_TOKEN secret is set). Live a couple of minutes after a push.
- The shields over YouTube's player carry a 1% tint and their own layer (`translateZ(0)`): iPad Safari lets touches through fully transparent boxes over the video. Keep that if they change.
- Local: `python3 -m http.server 8780` for the app and `npm start` in kids-tv-list for the lists on :8792 (the app picks localhost automatically).
- Stars, today's count and settings live in the device's localStorage, per channel (`tv-<kid>-…`); the grown-up code is shared (`tv-code`).
